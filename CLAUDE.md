## Frontend Design Guidelines
When building any frontend UI, follow this design thinking process:

**Before coding, commit to a BOLD aesthetic direction:**
- Purpose: What problem does this interface solve? Who uses it?
- Tone: Pick an extreme — brutally minimal, maximalist, retro-futuristic, organic, luxury, editorial, brutalist, etc.
- Differentiation: What makes this UNFORGETTABLE?

**Aesthetics rules:**
- Typography: Choose distinctive, characterful fonts. NEVER use Inter, Roboto, Arial, or system fonts
- Color: Commit to a cohesive palette with CSS variables. Dominant + sharp accents
- Motion: CSS animations for HTML; Motion library for React. Staggered reveals on load
- Layout: Use asymmetry, overlap, diagonal flow, grid-breaking elements
- Backgrounds: gradient meshes, noise textures, geometric patterns, dramatic shadows

NEVER produce generic AI aesthetics — no purple gradients on white, no cookie-cutter layouts
NEVER converge on the same fonts/colors across different projects
